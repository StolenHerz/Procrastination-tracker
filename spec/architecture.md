# Архитектура

## Модули

| Модуль | Ответственность |
|--------|-----------------|
| `main.py` | точка входа, сборка зависимостей, жизненный цикл приложения |
| `config.py` | константы, размеры окон, пути, параметры темы |
| `logging_config.py` | настройка консольного и файлового логирования |
| `database.py` | схема SQLite, CRUD, журнал, статистика, настройки |
| `timer.py` | фоновый таймер и потокобезопасные события |
| `ui_popup.py` | всплывающее окно проверки активности |
| `ui_main.py` | главное окно настроек и статистики |
| `tray_manager.py` | иконка и меню системного трея |

## Потоки

- **Главный поток** — единственный поток, которому разрешено вызывать Tkinter/CustomTkinter.
- **Поток таймера** — ждёт через `threading.Event`, не трогает UI и не открывает окна.
- **Поток pystray** — обрабатывает клики по иконке трея.

Обмен событиями:

```text
timer thread --(queue.Queue)--> main thread --(root.after)--> popup / main window
tray thread  --(queue.Queue)--> main thread
main thread  --(direct calls)--> timer / database
```

`root.after(...)` периодически читает очередь и выполняет действия в главном потоке.
Это исключает ошибку `main thread is not in main loop`.

## База данных

- `sqlite3`, файл `data.db` рядом с приложением или exe.
- На каждую операцию открывается отдельное соединение.
- Включены `WAL`, `foreign_keys` и `busy_timeout`.
- Соединения не разделяются между потоками.
- Схема создаётся через `CREATE TABLE IF NOT EXISTS`.

## Жизненный цикл

1. Настройка логирования.
2. Инициализация базы данных и стандартных активностей.
3. Создание скрытого главного окна Tk.
4. Запуск таймера и иконки трея.
5. Периодическая обработка очереди событий.
6. При срабатывании таймера — показ popup.
7. При выходе — остановка таймера, трея и уничтожение Tk.

## Обработка ошибок

- `database.py` оборачивает `sqlite3.Error` в `DatabaseError`.
- UI показывает ошибки через диалоги и статусные сообщения.
- Ошибки фоновых потоков логируются и не завершают приложение.
- При недоступности файла лога приложение продолжает работу с консольным логом.
