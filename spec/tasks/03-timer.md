# Этап 03. Таймер

## Задачи 020–026

- **020** — `TimerState` (`idle`, `running`, `paused`) и снимок состояния.
- **021** — фоновый поток, `threading.Event`, корректная остановка.
- **022** — `start`, `stop`, `reset`.
- **023** — `pause`, `resume` с сохранением остатка.
- **024** — изменение интервала без пересоздания потока.
- **025** — `queue.Queue` для событий `expired`, `started`, `paused`, `stopped`.
- **026** — тесты жизненного цикла на коротких интервалах.

## Правила

- Поток таймера не вызывает Tkinter.
- Все публичные методы потокобезопасны (`threading.Lock`).
- Событие срабатывания не теряется при паузе.
- `stop()` завершает поток в пределах разумного таймаута.

**DoD:** тесты не «висят», повторный `start()` не создаёт второй поток.
