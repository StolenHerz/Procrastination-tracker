# Этап 06. Системный трей

## Задачи 047–052

- **047** — `TrayManager` с `pystray.Icon` и иконкой из `assets/`.
- **048** — пункт «Открыть» показывает главное окно.
- **049** — «Пауза»/«Продолжить» синхронизирован с состоянием таймера.
- **050** — «Проверить сейчас» инициирует popup.
- **051** — «Выход» останавливает таймер, трей и Tk.
- **052** — закрытие главного окна скрывает его, приложение остаётся в трее.

## Правила

- Колбэки pystray не вызывают Tkinter напрямую.
- Действия из трея попадают в общую очередь событий.
- Повторный запуск приложения не создаёт вторую иконку.

**DoD:** приложение полностью управляется из трея, процесс завершается без «хвостов».
