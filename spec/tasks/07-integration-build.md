# Этап 07. Интеграция, сборка и документация

## Задачи 053–056. Интеграция

- **053** — `main.py` создаёт `Database`, `Timer`, окна и `TrayManager`.
- **054** — `EventPump`: `root.after(100, ...)` читает общую очередь.
- **055** — первый запуск показывает окно, последующие — скрытый старт;
  защита от второго экземпляра через именованный mutex Windows.
- **056** — `shutdown()`: остановка таймера, трея, закрытие логов.

## Задачи 057–060. Сборка

- **057** — `assets/icon.png` и `assets/icon.ico`.
- **058** — `ProcrastinationTracker.spec`, `--noconsole`, сборка `data.db` рядом с exe.
- **059** — `build.ps1`: установка зависимостей и запуск PyInstaller.
- **060** — README: запуск из исходников, сборка, частые ошибки.

## DoD

- `python main.py` запускает приложение из исходников.
- `dist/ProcrastinationTracker.exe` запускается на чистой Windows.
- После перезапуска настройки и статистика сохраняются.
- README позволяет новому пользователю собрать проект без подсказок.
