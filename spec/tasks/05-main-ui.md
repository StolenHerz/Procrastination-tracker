# Этап 05. Главное окно

## Задачи 034–041. Настройки и активности

- **034** — `MainWindow` с вкладками «Таймер», «Активности», «Статистика».
- **035** — поле интервала, валидация, сохранение через БД.
- **036** — список активностей с отметкой стандартных.
- **037** — диалог добавления с проверкой ошибок.
- **038** — диалог переименования.
- **039** — подтверждение удаления и объяснение ограничений.
- **040** — статусная строка и диалоги ошибок.
- **041** — единые отступы, размеры кнопок, тёмная/светлая тема.

## Задачи 042–046. Статистика

- **042** — итоги по активностям за 7 дней.
- **043** — гистограмма по дням на `tkinter.Canvas`.
- **044** — таблица последних записей.
- **045** — обновление после нового check-in.
- **046** — пустые состояния и подписи осей.

## DoD

- Изменения сохраняются после перезапуска.
- Ошибки БД показываются пользователю, приложение не падает.
- Окно остаётся читаемым при минимальном размере.
