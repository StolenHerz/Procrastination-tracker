# Этап 02. База данных

## Задачи 007–014

- **007** — `DatabaseError`, `ActivityExistsError`, `default_db_path`,
  `_connect`, `busy_timeout`, безопасное закрытие соединения.
- **008** — `_SCHEMA_SQL`: `activities`, `logs`, `settings`, индексы, WAL.
- **009** — стандартные активности только при пустой таблице.
- **010** — `Activity`, `list_activities`, `get_activity`.
- **011** — `add_activity`, `rename_activity`, `delete_activity`, проверки имён.
- **012** — `log_activity`, `recent_logs`, нормализация времени.
- **013** — `activity_totals`, `daily_totals`, заполнение пустых дней.
- **014** — `timer_interval_minutes`, валидация 1–1440, self-check.

## Ограничения

- Стандартные активности нельзя удалять.
- Активность с записями в журнале нельзя удалять.
- Названия уникальны без учёта регистра, максимум 50 символов.
- Все соединения открываются на одну операцию.

## DoD

- Схема создаётся при первом запуске.
- Повторная инициализация не дублирует данные.
- `python database.py` выполняет самопроверку на временной БД.
- Ошибки SQLite не выходят наружу как `sqlite3.Error`.

## Задачи 015–019. Тесты

- временная БД через `tempfile.TemporaryDirectory`;
- схема и стандартные активности;
- CRUD, дубли, пустые имена, защита от удаления;
- журнал, последние записи и сортировка;
- статистика за период и настройки интервала.

**DoD:** `python -m unittest discover -s tests` проходит.
