# Procrastination Tracker — спецификация

## О проекте

Лёгкое десктопное приложение для Windows, которое помогает замечать прокрастинацию.
Приложение живёт в системном трее, периодически спрашивает «Чем вы сейчас занимаетесь?»
и сохраняет ответы в локальную базу данных.

## Стек

- Python 3.10+
- `customtkinter` — интерфейс
- `pystray` + `Pillow` — системный трей
- `sqlite3` — локальное хранилище
- `PyInstaller` — сборка Windows-приложения

## Статус

MVP в разработке. Источник истины по задачам — [`backlog.md`](backlog.md),
по датам и сообщениям коммитов — [`schedule.csv`](schedule.csv).

## Структура `spec/`

| Файл | Назначение |

| `README.md` | цель, стек и правила работы |

## Правила разработки

- Одна задача из backlog = один логически цельный коммит.
- Сообщения коммитов — Conventional Commits на английском языке.
- Код использует type hints; исключения обрабатываются на границах модулей.
- Тесты логики — `unittest` из стандартной библиотеки.
- Перед коммитом: `python -m compileall .` и/или `python -m unittest discover -s tests`.
- Пустые и декоративные коммиты не создаются.
- Секреты, локальная база `data.db` и артефакты сборки в репозиторий не попадают.
