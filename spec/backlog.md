## Общее определение готовности

Задача считается готовой, если:

1. Изменение относится только к её области.
2. Код компилируется: `python -m compileall .`.
3. Для логики добавлены или обновлены тесты (где применимо).
4. Нет новых ошибок в консоли при ручной проверке.
5. Сообщение коммита совпадает с `schedule.csv`.
