# Требования MVP

## Цель

Дать пользователю минималистичный инструмент, который в фоне напоминает о проверке
текущего занятия, сохраняет историю ответов и показывает простую статистику.

## Функциональные требования

### 1. Фоновая работа и трей

- Приложение запускается без обязательного показа главного окна.
- Иконка приложения активна в системном трее.
- Меню трея позволяет открыть главное окно и завершить приложение.
- Закрытие главного окна сворачивает приложение в трей, а не завершает его.

### 2. Таймер

- В фоне работает таймер с настраиваемым интервалом.
- Значение по умолчанию — 25 минут.
- Допустимый интервал — от 1 до 1440 минут.
- Изменение интервала сохраняется в базе и применяется к следующему циклу.
- Таймер можно поставить на паузу, продолжить и перезапустить вручную.

### 3. Всплывающее окно

- По срабатыванию таймера поверх остальных окон появляется небольшое окно.
- Текст вопроса: «Чем вы сейчас занимаетесь?».
- Кнопки активности формируются из базы данных; стандартные виды идут первыми.
- Нажатие на активность:
  - сохраняет запись в журнал;
  - сбрасывает таймер;
  - закрывает всплывающее окно.
- Кнопка «Настройки / Статистика» открывает главное окно.
- Окно можно закрыть без выбора активности; таймер при этом продолжает новый цикл.

### 4. Главное окно

- Редактирование интервала таймера в минутах.
- Просмотр списка видов деятельности.
- Добавление пользовательского вида деятельности.
- Переименование вида деятельности.
- Удаление пользовательского вида деятельности, по которому ещё нет записей.
- Статистика за последние 7 дней:
  - количество записей по каждому виду деятельности;
  - простая гистограмма по дням;
  - список последних записей.

### 5. База данных

- Файл `data.db` создаётся автоматически при первом запуске.
- Схема создаётся идемпотентно, без потери существующих данных.
- Стандартные виды деятельности добавляются только в пустую таблицу.
- Все операции с базой обрабатывают ошибки и не роняют приложение.

## Нефункциональные требования

- Работа без интернета.
- Windows 10/11.
- Один экземпляр приложения.
- Tkinter-вызовы выполняются только в главном потоке.
- Понятные сообщения об ошибках на русском языке.
- Локальные логи в папке `logs/`.

## Критерии готовности MVP

1. Приложение запускается, сворачивается в трей и завершается через меню.
2. Таймер срабатывает с заданным интервалом.
3. Popup показывает активности, сохраняет выбор и перезапускает таймер.
4. Настройки интервала и активностей сохраняются после перезапуска.
5. Статистика за 7 дней отображается и обновляется после новой записи.
6. `python -m unittest discover -s tests` проходит успешно.
7. Приложение собирается PyInstaller и запускается без Python.

## Вне рамок MVP

- Облачная синхронизация и аккаунты.
- Уведомления Windows Toast.
- Автоматическое обновление.
- Экспорт данных в CSV/JSON.
- Гибкое расписание по дням недели.
