# Модель данных

## Файл

`data.db` — SQLite 3, создаётся автоматически. Для сборки PyInstaller файл
располагается рядом с исполняемым файлом.

## Таблица `activities`

| Поле | Тип | Ограничения | Назначение |
|------|-----|-------------|------------|
| `id` | INTEGER | PK, AUTOINCREMENT | идентификатор |
| `name` | TEXT | NOT NULL, UNIQUE, COLLATE NOCASE | название |
| `is_default` | INTEGER | NOT NULL, CHECK 0/1 | стандартная активность |

Стандартные значения: «Учёба/работа», «Прокрастинирую», «Отдыхаю».
Стандартные активности нельзя удалять. Пользовательские активности с записями
в журнале тоже нельзя удалять, чтобы не терять историю.

## Таблица `logs`

| Поле | Тип | Ограничения | Назначение |
|------|-----|-------------|------------|
| `id` | INTEGER | PK, AUTOINCREMENT | идентификатор записи |
| `activity_id` | INTEGER | NOT NULL, FK → `activities.id` | активность |
| `timestamp` | TEXT | NOT NULL | локальное время ISO 8601 |

Внешний ключ использует `ON DELETE RESTRICT`.

Индексы:

- `idx_logs_timestamp` — выборки и статистика по периоду;
- `idx_logs_activity_id` — группировка по активности.

## Таблица `settings`

| Поле | Тип | Ограничения | Назначение |
|------|-----|-------------|------------|
| `key` | TEXT | PK | имя настройки |
| `value` | TEXT | NOT NULL | значение |

Известные ключи:

- `timer_interval_minutes` — интервал таймера, целое число 1–1440.

## Формат времени

Время хранится как локальная строка `YYYY-MM-DD HH:MM:SS` без микросекунд.
Такой формат корректно сортируется и поддерживает SQLite-функцию `date()`.

## Основные запросы

- последние записи: `ORDER BY timestamp DESC, id DESC`;
- статистика по активностям: `LEFT JOIN logs` за период;
- статистика по дням: `GROUP BY date(timestamp)` с заполнением пустых дней в Python.

## Миграции

Для MVP достаточно идемпотентного `CREATE TABLE IF NOT EXISTS`.
При добавлении новых полей в следующих версиях будет отдельный модуль миграций.
